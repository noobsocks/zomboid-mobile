# DEAD TOWN

탑뷰 좀비 생존 모바일 웹게임 (아이폰 14 Pro 가로 852×393 전용 — 폰이 세로로 인식돼도 화면을 돌려 가로로 표시, SVG 렌더링)

## 플레이
- 왼쪽 조이스틱: 살짝 밀면 걷기(조용) · 중간은 달리기 · 끝까지 밀면 질주(빠르지만 시끄럽고 지구력 소모). 조이스틱 바깥 링 = 지구력
- 빨간 버튼: 공격 (누르고 있으면 연속 공격)
- 가구·좀비 시체 근처에서 이름 버튼: 수색 (시체에서는 옷·붕대·탄약 등이 나옴) / 가방: 먹기·마시기·장착·잠자기·저장·제작
- 화면 아래 추천 버튼: 출혈이면 붕대, 배고프면 먹기 등 1탭 실행
- 밤(21~05시)에는 시야가 좁아지고 좀비가 빨라짐 · 가로등이 켜짐
- 날씨: 비가 오면 소리가 묻혀 좀비가 덜 듣고, 시야는 조금 좁아짐. 폭우엔 천둥
- 캐릭터 꾸미기: 타이틀 화면에서 피부·머리모양·머리색·자켓 선택(무작위 가능). 다치면 옷에 피, 붕대 감으면 팔에 붕대, 양손무기는 두 손으로 쥠
- 좀비 9종: 시민·회사원·후드·경찰·의료진·작업자·조깅·노인·군인 — 모자·조끼·배지·마스크·절뚝임·팔 없음 등. 직업별로 시체에서 나오는 물건이 다름(경찰=탄약, 의료진=붕대·약)
- 마을: 160×160칸 (예전의 약 5배) — 주택가·공원·숲·주차장 블록이 섞여 있고, 새 게임마다 집·가구·루팅이 랜덤
- 움직임: 바로 최고 속도가 나지 않고 약 0.3초에 걸쳐 속도가 붙음. 멈출 때 살짝 미끄러지고, 크게 방향을 틀면 잠깐 느려짐
- 웅크리기(조이스틱 위 버튼 / 키보드 C): 느리게 걷지만 발소리가 거의 안 나고 좀비가 잘 못 봄
- 화면 확대·축소: 오른쪽 위 + − 버튼 · 두 손가락 벌리기/모으기 · 마우스 휠 · 키보드 + −
- 무기 등급: 하급(맨손·식칼·망치) 1명 · 일반(야구방망이·쇠파이프·못 박힌 판자·창) 2명 · 고급(도끼) 3명까지 동시 타격
- 좀비 종류: 러너(주황 고리, 쫓을 때 매우 빠름) · 뚱보(연두 고리, 느리지만 체력 2.6배·잘 안 밀림) · 비명 좀비(보라 고리, 나를 보면 소리 질러 주변 좀비를 부름) · 군인(체력 1.8배) · 경찰(체력 1.3배)
- 좀비는 나를 놓치면 마지막으로 본 곳까지 가서 주변을 두리번거리며 찾음. 평소엔 3~9초마다 근처를 배회
- 폐차 수색 가능 (타지 않은 차) · 도끼로 나무 베기 → 통나무 → 톱으로 판자 3개
- 분해: 목공 레벨이 낮으면 재료가 하나씩 부서질 수 있음 (Lv0 30% → 레벨당 3%p↓ → Lv10 0%), 분해 시간도 레벨당 5% 빨라짐 (Lv10 절반). 분해하면 목공 경험치
- 판자 구하는 법: ① 옷장·서랍장·조리대를 망치로 분해 ② 철물점 공구 선반 ③ 나무 베기(도끼) + 톱
- 가방: 같은 물건(같은 신선도)은 한 칸으로 묶어 표시 (x개수). 수색 창에서 묶음을 누르면 한 번에 챙김
- 창문 안쪽이 가구로 막혀 있으면 '창문 넘기'가 빨간색으로 표시됨
- 특수 건물 9곳: 마트 2·약국 2·경찰서·철물점 2·주유소 2 (간판 있음, 큰 지도에 이름 표시). 좋은 물건일수록 좀비가 많음 — 경찰서는 총·탄약, 약국은 붕대·약, 철물점은 판자·못·공구, 마트·주유소는 음식
- 좀비 떼: 1~2분마다 멀리 있는 좀비 무리가 한꺼번에 이동 (절반 이상은 플레이어 근처로). 가까이 오면 '무리 지은 신음' 알림
- 헬기 이벤트: 첫날 오후~셋째 날 사이 한 번, 이후 2~4일마다. 날아와서 약 40초간 머리 위를 맴돌며 큰 소음 → 주변 좀비가 몰려옴 (자고 있으면 깸)
- 걸음새: 걷기·달리기·질주에 따라 보폭과 팔 흔들림이 커지고, 질주할 땐 상체를 숙임. 좀비는 한쪽 발을 끌며 비틀거림
- 메뉴 → 폰 설정: 성능 모드(안개 결·비 입자 줄임, 새 게임부터 좀비 30% 적게) · 조작 오른손/왼손(조이스틱과 버튼 좌우 바꿈) · 버튼 크기 작게/보통/크게
- 시야 안개: 캐릭터가 바라보는 곳만 선명하고, 지나온 곳은 약 10초에 걸쳐 서서히 안개로 덮임. 안 가본 곳은 처음부터 안개
- 지도(미니맵·큰 지도): 가본 곳만 표시됨. 큰 지도는 탐험한 범위에 맞춰 자동 확대
- 예전 저장(72칸 마을)은 이어하기 시 예전 마을 그대로 불러옴 (새 게임부터 큰 마을)
- 집마다 바닥(원목·짙은 나무·카펫·타일·체크무늬)과 가구(책장·욕조·세면대·세탁기·화분·책상 추가)가 다름. 밖에는 잡초·꽃·낙엽·기름때·웅덩이·타이어 자국·상자·깨진 유리 등 소품
- 침대 옆에서 자면 더 빨리 회복
- 문·창문: 가까이 가면 '행동' 버튼 → 문 열기/닫기, 창문 깨기/넘기, 판자로 막기/떼기(망치+바리케이드 판자). 닫힌 문으로 걸어가면 자동으로 열림
- 좀비는 막힌 문·창문을 두드려 부숨 (쾅 소리에 다른 좀비도 모여듦)
- 가구 옮기기: 빈 가구·침대·소파 등을 '들기' → 가방에서 '내려놓기'로 원하는 곳에 배치(입구 막기 가능)
- 기술: 근접 전투·사격·목공·요리·응급처치 — 할수록 레벨업 (가방 → 능력 탭)
- 요리: 전기 있을 땐 조리대, 정전되면 모닥불(판자2+천1). 데운 통조림·토스트·스튜(냄비 필요)
- 음식은 시간이 지나면 시들고 상함(상한 음식은 식중독 위험). 냉장고는 전기 있을 때 4배 느리게 상함
- 6~9일차 사이 어느 날 전기가 끊김: 가로등·냉장고·조리대 정지
- 30초마다, 그리고 앱을 벗어날 때 자동 저장. 죽으면 저장 기록 삭제(영구 사망)
- 효과음: 음원 파일 없이 게임 안에서 합성 (메뉴 → 소리 켜기/끄기). 아이폰 무음 모드에서는 소리가 나지 않음

## 자동차 운전
- 도로 위 멀쩡한 차 중 일부(약 90대)는 운전 가능. 열쇠는 꽂혀 있거나(약 1/3) 근처 집 서랍·옷장·계산대에 있음 — 열쇠 설명에 "차가 북동쪽 약 30칸"처럼 방향 표시
- 차 옆 "차에 타기" → 조이스틱으로 방향·가속, 반대로 당기면 브레이크·후진, 빨간 버튼 = 경적(좀비를 부름)
- 도로 최고 약 72km/h, 흙길·풀밭은 느림 · 연료(달릴수록 줄어듦, 주유소 주유기에서 주유 — 정전 전까지만) · 차 상태(충돌·좀비·두드림으로 줄어듦)
- 빠르게 치면 좀비가 쓰러짐(차도 상함) · 엔진 소리가 주변 좀비를 부름 · 차 안에서는 좀비가 차를 두드림
- 차 뒤쪽에서 "자동차 트렁크" 수색·보관 · 세워 둔 차는 길을 막음
- 운전 중엔 화면이 조금 멀어지고, 시속 20km를 넘으면 카메라가 진행 방향 앞쪽으로 부드럽게 이동(60km/h에서 최대) · 시야 거리도 늘어남

## 가방 정리 · 보관 한도
- 가방 물건이 **무기 / 음식 / 의료 / 재료 / 기타** 로 묶여 보이고, 종류마다 칸 수·무게가 나옴
- 위쪽 버튼으로 한 종류만 보기 (마지막 선택은 기억됨)
- 정렬: 무기는 장착 중 → 센 순서(탄약은 뒤), 음식은 상하기 직전 것 먼저, 의료는 붕대 먼저
- 카드마다 무게 표시, 상해가는 음식은 테두리로 표시
- 보관함마다 한도(kg): 서랍 4 · 찬장/카운터/가방 6 · 냉장고/사물함 8 · 상자 10 · 선반/공구대 12 · 옷장 15 · 트렁크 35 · 군용트럭 60 · 시체 10
- 넣을 때 자리가 모자라면 "공간이 부족하다", 묶음은 들어가는 만큼만 넣음

## 메뉴 화면 (전체 화면)
- 가방 버튼 → 왼쪽 메뉴: **가방 / 장비 / 제작 / 능력 / 수첩**, 오른쪽: 고른 물건 정보와 버튼
- 메뉴를 열어도 게임 시간은 흐름 → 좀비가 10m 안에 오면 위쪽에 "좀비 Nm", 맞으면 "공격받는 중!" 표시
- 수색: 왼쪽 보관함 | 오른쪽 내 가방

## 장비 칸
- 머리 · 상의 · 하의 · 신발 · 장갑 · 등(배낭) + 주무기 · 보조무기
- 방어: 맞을 때 피해 감소(최대 45%), 물림·긁힘 확률 감소. 맞을 때마다 입은 옷이 조금씩 닳음 (천·테이프로 수선)
- 배낭: 기본 10kg + 배낭 용량 (낡은 배낭 +5 · 책가방 +7 · 더플백 +10 · 등산 +12 · 군용 +15)
- 입은 옷은 무게의 30%만 계산, 배낭은 그대로
- 처음엔 낡은 자켓 · 청바지 · 운동화 · 낡은 배낭 (예전 저장도 똑같이 받음)
- 옷은 옷장·여행 가방·사물함·소방 장비함·군용 트럭 등에서, 직업 좀비에게서도 나옴
- 캐릭터 그림: 입은 상의 색, 멘 배낭 모양이 바뀜 (모자·헬멧은 아직 그림에 안 나옴)

## 빠른 버튼 · 기온 · 차 정비
- 빠른 칸: 음식·물·의료 물건 정보창에서 "빠른 칸" → 화면 아래 고정 (최대 3개, 개수 표시, 다 쓰면 같은 종류 다음 것)
- 무기 바꾸기: 보조무기를 넣으면 공격 버튼 왼쪽 위에 작은 버튼 → 한 번 누르면 주무기↔보조
- 기온: 시계 옆 온도계 (색·눈금으로 표시, 건물 안이면 "실내"). 날이 갈수록 추워지고(하루 0.35도), 새벽이 가장 춥고, 비 오면 -3도
- 체온: 건물 안 +7 · 차 안 +5 · 모닥불 옆 +12 · 옷 보온 · 뛰면 따뜻 · 비 맞으면 젖어서 추움
  - 추움(35.5도↓): 기력 빨리 줄고 회복 안 됨 · 저체온(34.8도↓): 체력 감소 · 더움/열사병은 반대로 목마름·체력 감소
- 기름통(10L): 주유기(전기 있을 때)에서 채우거나, 세워진 차에서 기름 빼기 → 내 차에 붓기. 가득 차면 약 8kg
- 차 고치기: 렌치 + 고철 1개 → 차 상태 +8% (정비 레벨마다 +2%)
- 정비 기술: 차 고치기·기름 옮기기로 오름 → 수리량↑ 작업 시간↓
- 모자·헬멧이 캐릭터 그림에 보임

## 상태별 화면 효과
- 가장자리 위주 (가운데 시야는 안 가림) · 여러 개면 가장 위험한 2개만
- 출혈: 빨간 두근거림(체력 낮을수록 빠름) + 걸을 때 핏방울 · 중상: 색이 빠지고 어두워짐
- 추움→저체온: 서리 (심하면 화면 떨림 + 입김) · 더움→열사병: 주황빛
- 피곤: 가끔 눈 깜빡 (심하면 반쯤 감김) · 지침: 숨 쉬듯 어두워짐 · 메스꺼움: 초록빛 + 울렁임
- 젖음: 물방울 · 굶주림/탈수: 칙칙해짐 · 배고픔은 배꼽시계, 목마름은 마른기침 소리
- 메뉴 → "흔들림·울렁임" 끄면 떨림·울렁임·움직이는 효과 모두 꺼짐
