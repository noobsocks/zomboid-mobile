# DEAD TOWN

탑뷰 좀비 생존 모바일 웹게임 (아이폰 14 Pro 가로 852×393 기준 (세로로 들면 안내 화면), SVG 렌더링)

## 플레이
- 왼쪽 화면 드래그: 이동 / 빨간 버튼: 공격 (누르고 있으면 연속 공격)
- 달리기: 빠르지만 소리가 커서 좀비가 몰려옴
- 가구 근처에서 가구 이름 버튼: 수색 / 가방: 먹기·마시기·장착·잠자기·저장
- 밤(21~05시)에는 시야가 좁아지고 좀비가 빨라짐
- 30초마다, 그리고 앱을 벗어날 때 자동 저장. 죽으면 저장 기록 삭제(영구 사망)

## 구조
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성 (HUD, 조이스틱, 버튼, 가방) |
| `style.css` | 디자인 · 아이폰 안전영역(노치/홈바) 대응 |
| `js/map.js` | 시드 기반 마을 생성 (도로·집·창문·가구·나무) |
| `js/astar.js` | 좀비 경로탐색 A* (8방향, 벽 모서리 끼기 금지) |
| `js/game.js` | 게임 로직 전체 (전투, 좀비 AI, 생존 수치, 낮밤, 저장) |

## GitHub Pages 배포
1. GitHub에서 새 저장소 생성 → 이 폴더 안 파일 전체 업로드 (또는 `git push`)
2. 저장소 Settings → Pages → Branch: `main` / `(root)` → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소명>/` 접속

## 아이폰에서 전체화면으로 실행
Safari로 위 주소 열기 → 공유 버튼 → **홈 화면에 추가** → 홈 화면 아이콘으로 실행
(주소창 없이 가로 852×393 전체 화면으로 실행됨)

## PC 테스트
`preview.html` 더블클릭 → 아이폰 14 Pro 가로 틀(다이나믹 아일랜드·홈바 포함) 안에서 실행
- 마우스: 왼쪽 아래 드래그 이동, 버튼 클릭
- 키보드: WASD 이동, Shift 달리기, Space 공격, E 수색, I 가방, M 지도
