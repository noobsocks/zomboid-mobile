# DEAD TOWN

탑뷰 좀비 생존 모바일 웹게임 (아이폰 14 Pro 가로 852×393 전용 — 폰이 세로로 인식돼도 화면을 돌려 가로로 표시, SVG 렌더링)

## 플레이
- 왼쪽 조이스틱: 살짝 밀면 걷기(조용) · 중간은 달리기 · 끝까지 밀면 질주(빠르지만 시끄럽고 지구력 소모). 조이스틱 바깥 링 = 지구력
- 빨간 버튼: 공격 (누르고 있으면 연속 공격)
- 가구·좀비 시체 근처에서 이름 버튼: 수색 (시체에서는 옷·붕대·탄약 등이 나옴) / 가방: 먹기·마시기·장착·잠자기·저장·제작
- 화면 아래 추천 버튼: 출혈이면 붕대, 배고프면 먹기 등 1탭 실행
- 밤(21~05시)에는 시야가 좁아지고 좀비가 빨라짐 · 가로등이 켜짐
- 날씨: 비가 오면 소리가 묻혀 좀비가 덜 듣고, 시야는 조금 좁아짐. 폭우엔 천둥
- 캐릭터 꾸미기: 타이틀 화면에서 피부·머리모양·머리색·자켓 선택(무작위 가능). 다치면 옷에 피, 붕대 감으면 팔에 붕대, 양손무기는 두 손으로 쥠
- 좀비 9종: 시민·회사원·후드·경찰·의료진·작업자·조깅·노인·군인 — 모자·조끼·배지·마스크·절뚝임·팔 없음 등. 직업별로 시체에서 나오는 물건이 다름(경찰=탄약, 의료진=붕대·약)
- 마을: 160×160칸 (예전의 약 5배) — 주택가·공원·숲·주차장 블록이 섞여 있고, 새 게임마다 집·가구·루팅이 랜덤
- 시야 안개: 캐릭터가 바라보는 곳만 선명하고, 지나온 곳은 약 10초에 걸쳐 서서히 안개로 덮임. 안 가본 곳은 처음부터 안개
- 지도(미니맵·큰 지도): 가본 곳만 표시됨. 큰 지도는 탐험한 범위에 맞춰 자동 확대
- 예전 저장(72칸 마을)은 이어하기 시 예전 마을 그대로 불러옴 (새 게임부터 큰 마을)
- 집마다 바닥(원목·짙은 나무·카펫·타일·체크무늬)과 가구(책장·욕조·세면대·세탁기·화분·책상 추가)가 다름. 밖에는 잡초·꽃·낙엽·기름때·웅덩이·타이어 자국·상자·깨진 유리 등 소품
- 침대 옆에서 자면 더 빨리 회복
- 문·창문: 가까이 가면 '행동' 버튼 → 문 열기/닫기, 창문 깨기/넘기, 판자로 막기/떼기(망치+바리케이드 판자). 닫힌 문으로 걸어가면 자동으로 열림
- 좀비는 막힌 문·창문을 두드려 부숨 (쾅 소리에 다른 좀비도 모여듦)
- 가구 옮기기: 빈 가구·침대·소파 등을 '들기' → 가방에서 '내려놓기'로 원하는 곳에 배치(입구 막기 가능)
- 기술: 근접 전투·사격·목공·요리·응급처치 — 할수록 레벨업 (가방 → 능력 탭)
- 요리: 전기 있을 땐 조리대, 정전되면 모닥불(판자2+천1). 데운 통조림·토스트·스튜(냄비 필요)
- 음식은 시간이 지나면 시들고 상함(상한 음식은 식중독 위험). 냉장고는 전기 있을 때 4배 느리게 상함
- 6~9일차 사이 어느 날 전기가 끊김: 가로등·냉장고·조리대 정지
- 30초마다, 그리고 앱을 벗어날 때 자동 저장. 죽으면 저장 기록 삭제(영구 사망)
- 효과음: 음원 파일 없이 게임 안에서 합성 (메뉴 → 소리 켜기/끄기). 아이폰 무음 모드에서는 소리가 나지 않음

## 구조
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성 (HUD, 조이스틱, 버튼, 가방) |
| `style.css` | 디자인 · 아이폰 안전영역(노치/홈바) 대응 |
| `js/map.js` | 시드 기반 마을 생성 (도로·집·창문·가구·나무) |
| `js/astar.js` | 좀비 경로탐색 A* (8방향, 벽 모서리 끼기 금지) |
| `js/game.js` | 게임 로직 전체 (전투, 좀비 AI, 생존 수치, 낮밤, 저장, 그래픽) |
| `js/audio.js` | 효과음·환경음 합성 엔진 |
| `sw.js` | 오프라인 실행(폰에 게임 파일 저장). 새 버전 올릴 때 `VERSION` 숫자를 올리면 폰에 즉시 반영 |

## GitHub Pages 배포
1. GitHub에서 새 저장소 생성 → 이 폴더 안 파일 전체 업로드 (또는 `git push`)
2. 저장소 Settings → Pages → Branch: `main` / `(root)` → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소명>/` 접속

## 아이폰에서 전체화면으로 실행
Safari로 위 주소 열기 → 공유 버튼 → **홈 화면에 추가** → 홈 화면 아이콘으로 실행
(주소창 없이 가로 852×393 전체 화면으로 실행됨)

## PC 테스트
`preview.html` 더블클릭 → 아이폰 14 Pro 가로 틀(다이나믹 아일랜드·홈바 포함) 안에서 실행
- 마우스: 왼쪽 아래 드래그 이동, 버튼 클릭
- 키보드: WASD 이동(달리기), Shift 질주, Ctrl 걷기, Space 공격, E 수색, F 문·창문·가구 행동, I 가방, M 지도

## 그림 크기 규격 (1칸 = 32px 기준)
코드 안에서는 "칸" 단위로 그림 (1px = 1/32칸). 규격표는 `js/game.js` 맨 위 `SPEC` 부분에도 있음.

| 대상 | 규격 (px) |
|---|---|
| 타일 1칸 | 32×32 |
| 캐릭터(플레이어·좀비) | 몸통 24×20 · 장비 포함 최대 26×24 |
| 시체 | 32×24 이하 |
| 1칸 가구(냉장고·조리대·서랍장·옷장·식탁·세탁기·책상 등) | 28×28 (사방 2px 여백) |
| 작업대 | 28×24 |
| 2칸 가구(침대·소파·욕조) | 60×28 |
| 자동차 | 26×60 |
| 나무 잎 | 지름 32~36 (잎만 칸 밖으로 살짝 허용) |
| UI 아이콘 | 24×24 |
